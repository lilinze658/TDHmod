德颂拉特大陆的纷争从未停息过，无论是曾经盛极一时的天使还是远古遗留的超古代，都在战争中消亡殆尽······

一个又一个时代过去，到如今这个新秩序时代，大陆战争的阴云尚未消散，秩序战争的号声已然迫近。伴随着洛维尼亚帝国国内矛盾的激化，贵族和皇室的冲突愈演愈烈，两者的割裂逐渐将曾经魔洲大陆最强盛的国家化作纷争的摇篮，亚人奴隶制所造成的危害更是加速了帝国的解体，洛维尼亚国内势力各个摩拳擦掌，等待着机会的到来。
洛维尼亚的宿敌们自然不会放过这个大好时机。在西方，洛维尼亚曾经的手下败将、第十次莫洛战争的失败者莫比斯帝国在元首艾普蒂菲的带领下疯狂的扩充着军队，并在国际社会上积极寻找盟友，以“复兴同盟”的名义等待彻底粉碎这个强大陶俑的机会；在东方，曾被洛维尼亚放逐的天翼族神权国度翼神教国也对其虎视眈眈，时时刻刻都在寻找着一个复仇的机会，试图将曾经所遭受的一切加倍奉还。
不仅是本土，洛维尼亚曾经的殖民地也遭到了严重威胁，奇恩帝国的迅速崛起打破了洛维尼亚苦心经营的西洲平衡战略。作为曾经的洛维尼亚殖民地，奇恩帝国不仅迅速的发展出了自己的工业体系，还长期积极参与各项反对洛维尼亚的事业，并致力于促进两奇统一，而作为洛维尼亚保护国的奇拉王国尚未建立自己的军工体系，仅保有大量成建制的骑兵部队，无力抵挡奇恩帝国的入侵，危在旦夕。
而洛维尼亚的传统盟友此时却各有难处，哈斯佩芙受到南方魔法少女的威胁，在法兰复国战争中节节败退，无力帮助洛维尼亚；神州则本就长期保持国际中立态度，又刚刚经历一场大叛乱，国内元气大伤，只求修养生息，无意于国际干涉，对洛维尼亚的求援视而不见。
与此同时，大陆的其他地区也动乱起来，全大陆迅速进入了战火飘摇的时代。在中州南部，里斯亚尼亚在席拉元帅统治下建立了绝对的军事独裁政体，在席拉对外扩张的战略方针指导下逐渐统一了各个中部小国，兵锋直指翼神教国；大陆边缘的交界群岛也建立起了新的强权升阳帝国，没人知道她们的目的是什么，除了亲手将她们驱逐出去的神州······
德颂拉特就在这样的动乱中逐步走到了大陆历的第四十六个世纪，步入了又一个被战争阴霾覆盖的时代。
德颂拉特大陆什么时候才能真正的迎来和平与发展呢？谁也不知道······
